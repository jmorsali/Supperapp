# Hummers app

MVP موبایل‌محور و PWA برای مدیریت دارایی، اعتبار تک‌خرید، فروش اعتباری و مدیریت عملیاتی هامرز است. این پروژه مستقل در پوشه `Supperapp` ساخته شده و طراحی موبایلی `hummers-app-front` را با Design System پروژه `leasing-backoffice-front` ترکیب می‌کند.

## اجرا

```bash
npm install
npm run dev
```

برنامه روی `http://localhost:3010` اجرا می‌شود. Build تولیدی با `npm run build` ساخته می‌شود.

## حساب‌های دمو

کد OTP در تمام سناریوها `12345` است.

| نقش | شماره موبایل |
|---|---|
| مشتری | `09120000001` |
| فروشگاه | `09120000002` |
| ادمین | `09120000003` |

شماره `09121112233` مشتری بدون احراز هویت را نمایش می‌دهد. داده‌ها در IndexedDB مرورگر باقی می‌مانند و ادمین می‌تواند آن‌ها را از داشبورد بازنشانی کند.

## فلوهای MVP

- ورود یکپارچه با موبایل و OTP و تشخیص نقش
- احراز هویت سطح یک از مسیر سجام/ثبت احوال
- احراز هویت سطح دو با کارت ملی، تصویر چهره و ویدئوی زنده و نتیجه ماک فینوتک
- خرید صندوق سیمرغ یا بیمه عمر با وضعیت صدور یک تا دو روزه
- ابطال بخش آزاد دارایی و جلوگیری از برداشت وثیقه مسدود
- اعتبار تا سقف ۷۰٪ ارزش آزاد دارایی و فقط یک اعتبار فعال
- انصراف کامل پیش از اولین خرید و آزادسازی وثیقه
- فاکتور چندکالایی شامل تعداد، تخفیف، مالیات و سهم پرداخت خارج از سامانه
- آزادسازی وثیقه اضافه پس از خرید و ارزیابی قطعی سه‌مرحله‌ای
- تشکیل قرارداد و جدول اقساط پس از تأیید ارزیاب سوم
- مدیریت کالا، موجودی، فروش و تسویه برای پذیرنده
- مدیریت کاربران، فروشگاه‌ها، نمایش طرح‌ها، سناریوهای زمانی و وصول دستی وثیقه برای ادمین
- Service Worker، manifest و Notification API برای PWA

## Mock API

| مسیر | کاربرد |
|---|---|
| `POST /api/mock/auth/otp` | ارسال OTP |
| `POST /api/mock/kyc/sejam` | استعلام سجام و مسیر جایگزین ثبت احوال |
| `POST /api/mock/kyc/finnotech?scenario=approved` | تطبیق سطح دوم |
| `GET /api/mock/leasing/programs` | برنامه‌های قابل ارائه در اپ |
| `POST /api/mock/payment` | پرداخت با سناریوهای موفق، ناموفق و timeout |
| `GET /api/mock/health` | سلامت Mock Backend |

سناریوهای فینوتک: `approved`، `mismatch`، `low-quality`، `invalid-document` و `service-error`.

## نکات معماری

- واحد نمایش اپ تومان است. در اتصال واقعی به لیزینگ تبدیل تومان به ریال در مرز API انجام خواهد شد.
- `isAvailableInHummersApp` فلگ پیشنهادی برای کنترل نمایش Policyهای لیزینگ است.
- Push واقعی در حالت بسته‌بودن کامل مرورگر به Push Server و VAPID نیاز دارد. MVP ساختار Service Worker و اعلان محلی را فراهم می‌کند.
- تست‌های unit، integration و E2E و Docker طبق تصمیم محصول به فاز بعد منتقل شده‌اند.
